# Last 6 Bullet

> 총알이 여섯 발뿐인 무법 마을. 내가 빗맞힌 한 발은 곧 무법자의 탄약이 된다.

2D 게임 프로그래밍 (2026-2학기) 1차 프로젝트 · 2023148012 손세민

## 게임 소개

탑뷰 아레나 액션 슈팅 게임이다. 구역 안에 존재하는 총알 수가 고정되어 있고, 쏜 총알은 바닥에 떨어진다. 그 총알을 플레이어와 적이 함께 주워 쓰기 때문에, 바닥의 총알 한 발을 두고 쟁탈전이 벌어진다.

- 장르: 탑뷰 아레나 액션 슈팅
- 개발 환경: Python 3.13, pico2d 1.5.1
- 목표: 술집, 광산, 달리는 기차, 은행 4구역을 돌파하고 은행의 두목을 쓰러뜨린다

자세한 기획은 [PRD.md](PRD.md)에 있다.

## 조작 (예정)

| 입력 | 동작 |
|---|---|
| W A S D | 8방향 이동 |
| 마우스 | 조준 |
| 마우스 왼쪽 클릭 | 발사 |
| Space 또는 마우스 오른쪽 클릭 | 발차기 |
