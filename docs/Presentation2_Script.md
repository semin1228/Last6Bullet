## 촬영 요령

- `tools/record.py`로 다섯 장면을 자동 조작으로 녹화할 수 있다(`demo_video/s1_shoot.mp4` ~ `s5_mine.mp4`, 이어 붙인 `demo_all.mp4`, 약 33초). 목소리는 따로 녹음해 편집으로 맞춘다.

- 한 번에 이어서 찍기 어렵다. 장면마다 따로 여러 번 찍고, 잘 나온 부분만 잘라 이어 붙인다.
- **F2**를 누르면 적을 다 쓰러뜨리지 않아도 다음 구역(광산)으로 넘어간다. 광산 장면만 따로 찍을 때 쓴다.
- **F1**(FPS와 총알 장부)은 끄고 찍는다. 켜면 위쪽에 디버그 글자가 나온다.
- 창 크기는 1280×720 그대로 녹화한다. 글자가 또렷해야 한다(발표 가이드).
- 술꾼은 계속 달려들어 장면을 방해하므로, 술집 장면은 술꾼을 먼저 두 발로 쓰러뜨리고 시작하면 편하다.
- 녹음한 뒤 반드시 직접 재생해서 소리와 글자를 확인한다(발표 가이드).
